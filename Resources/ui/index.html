支持 Qwen3-TTS 12Hz 的官方 BF16 safetensors 目录，包含 speech_tokenizer。单个权重文件、MLX 权重、GGUF 和其他语音模型不能直接导入。运行时 INT8 / INT4 由内置引擎处理。

BUILT FOR YOUR MAC

环境与帮助

首次启动自动准备应用私有运行时，不安装系统级包，不更改系统 Python。

这版程序的功能边界

这是面向 Intel Mac 的原生桌面程序，使用社区 C 引擎 f1b6865。编译下限为 macOS 10.15；旧系统与 2019 Mac Pro 的实际稳定性仍需实机验证。不是官方 Python 推理程序的完整替代。

功能当前支持情况
Base 声音克隆、CustomVoice 预设、VoiceDesign 设计已接入 · 需要对应模型
文本导入、分段、重生成、声音档案已接入
语速、音量、裁剪、音高、WAV 导出已接入 · 后期处理创建副本
官方训练、微调、LoRA 训练不支持

自动升级操作系统 / 增加内存无法自动完成；会显示诊断

快速开始

  1. 等待环境检测完成，确认“引擎就绪”。
  2. 到模型管理下载 0.6B Base，或导入完整官方模型目录。
  3. 在工作室选择本人参考录音，填写录音对应文字。
  4. 输入一句测试文字，点击生成；首次不要输入整本书。
  5. 试听后调整参数，或导出 WAV。长文逐段生成，已完成片段自动保存。

模型下载访问所选的魔搭 / Hugging Face 及其文件存储 CDN。推理完全在本机，不需要账号或 API Key。系统空间不足、网络不可用、模型格式错误等情况会显示具体错误；程序不会关闭系统安全功能或绕过管理员授权。

日志可能包含文稿片段和本地路径，分享前请检查。模型生成速度和音色质量尚未在你的设备上验证。
